🚀 Quick Launch — luncurkan token dalam 5 langkah

Isi nama, logo, dan modal — sisanya dipandu langkah demi langkah. Modal dipakai untuk beli pertama token kamu sendiri. Setiap transaksi hanya terkirim setelah kamu klik tombolnya dan konfirmasi di wallet kamu sendiri. Testnet saja — aset di sini tidak bernilai.

  1. 1. Preview Config — template #6, supply 1.000.000 token, threshold = modal, creator 70%. belum jalan
  2. 2. Create Config — buat Config di registry. menunggu preview
  3. 3. Issue token — terbitkan token + metadata logo. menunggu Config
  4. 4. Wrap modal — ubah ETH jadi WETH untuk beli. menunggu token
  5. 5. Buy pertama — beli token sendiri sebesar modal. menunggu wrap

Yang terjadi di balik layar: Config dibuat dari template #6 (Concentrated graduation) dengan supply 1.000.000 token dan threshold = modal kamu; token diterbitkan dengan desimal 9; modal di-wrap jadi WETH lalu dipakai beli token di kurvanya. Setelah buy pertama sebesar modal penuh, kurva hampir penuh (tersisa sedikit token) — token masih bisa diperdagangkan sampai batasnya, lalu perlu migrasi ke pool.

📈 Boost volume — naikkan volume token sendiri

Untuk testing di testnet saja. Loop buy → sell di curve yang sedang dimuat: beli sebesar jumlah per trade, lalu jual kembali semua token yang didapat, diulang sesuai siklus. Setiap transaksi tetap preview dulu dan hanya terkirim setelah kamu konfirmasi di wallet — tidak ada transaksi yang jalan sendiri.

Muat dulu sebuah curve (lewat Quick Launch, Explore, atau Trade di bawah).

Batas keamanan: total belanja per run maksimal 0,05 WETH (siklus × jumlah per trade). Setiap siklus kehilangan sedikit WETH karena fee kurva (pada tes: ~2% per siklus). Pastikan saldo WETH cukup untuk satu trade + ETH untuk gas tiap transaksi (2 tx per siklus).

Launch — create a Config

Derived from a reviewed template (default #6, Concentrated graduation). The preview step is real and was verified live: it prints a reviewHash that binds chain, registry and exact calldata — creating requires re-running the preview and matching that hash. No key or funds are used for the preview.

Launch — issue a token

poolCreationFee is paid in native ETH as the transaction value and is read from the Config — the docs example is 0, but the real value must be checked per Config.

Fees — claimable

The FeeVault aggregates fees across all launches for the same asset + beneficiary — a claimable amount is not the revenue of one token. A zero claimable amount sends no transaction.

Demo: FeeVault for the KGPT curve is 0x414Be4a093fDFd7292dCa95C4D6fdD3905Ee6800 (read from the factory — the UI always reads the vault from the factory, never trusts a pasted address).
